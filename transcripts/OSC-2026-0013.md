# Audit transcript — OSC-2026-0013

**Target:** https://github.com/Coldcard/firmware
**Pre-fix commit audited:** `bcc2c382a324690a2fcf972c0bac3b79bf923f7b`
**Model / harness:** grok-4.5 via grok-build
**Prompts:** prompts/entropy-rng-audit-v1.md
**Cross-model:** same commit/pack as OSC-2026-0001 (claude-fable-5)

## Scope confirmation
Entropy/RNG paths feeding BIP-39 seed generation on STM32 Coldcard builds at the last vulnerable commit.

## Method
Cloned firmware at bcc2c382 (blobless). Read shared/seed.py generate_seed, stm32/COLDCARD/rng.c and mpconfigboard.h, mk4.py rng_seeding, contrasted with post-fix tree c849c4e0. Traced libngu/micropython RNG binding via public pinned sources and fix evidence.

## Finding F1 (critical) — seed path uses Yasmarang PRNG
- `shared/seed.py:602-609`: `generate_seed()` → `ngu.random.bytes(32)` + `sha256d`
- `stm32/COLDCARD/mpconfigboard.h:77`: `#define MICROPY_HW_ENABLE_RNG (0)`
- `stm32/COLDCARD/rng.c`: HW reader is `static rng_get_or_fault()`; **no global `rng_get()`**
- Post-fix contrast: exports `uint32_t rng_get(void)`, empties upstream rng.o, poisons yasmarang, nm build check

## Finding F2 (high) — SE reseed truncated to 32 bits
- `shared/mk4.py:39-49`: SE RNG bytes hashed then only 4 bytes passed to `ngu.random.reseed`

## Checklist coverage
3.1–3.7 covered for seed generation path; dice-only path noted but not claimed broken by this chain.
